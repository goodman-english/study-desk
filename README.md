# Study Desk

One-hour self-study sessions that teach one Claude Code capability each and bolt it onto Sándor's own agents (first track: the Globus admin agent).

- `index.html` — the page: journey map on top, the open session below as a workbench (read → watch → check on the left, build console on the right). Clips are YouTube embeds that start at the right second. Progress is saved in the browser; "Copy my progress" exports it.
- `sessions/index.json` — the track: session list, what each adds to the agent, the parked shelf.
- `sessions/sNN.json` — one session: reading, figure, clips (video id + start second), checks, build steps with copy-able prompts, what you leave with, what comes next.

Live at https://goodman-english.github.io/study-desk/ (GitHub Pages, from `main`).

Built 28 Oct 2026 in a Claude session from the brief "Self-Study Engine Foundations". The session writer (a skill that turns flagged videos into a session file) and the fishnet (weekly video search scored against the gold standards) come next.
