# Study Desk — rules for Claude working in this folder

1. This repository is a public website. Never put Globus student names, course records, invoices or anything from the Globus portal here; course IDs in examples are fine.
2. One session = one file in sessions/ (sNN.json). The page renders it; do not hand-write session HTML.
3. Every clip needs a YouTube video id and a start second that was checked against the transcript (what is said) or Gemini's screen sheet (what is shown). No guessed time codes.
4. Reading text is in plain English with jargon defined on first use; British spelling; Budapest time only.
5. Every session must end with something real that goes into the agent folder, and must say what it adds to the agent.
6. Keep the page at 18px base type or larger; full page width.
